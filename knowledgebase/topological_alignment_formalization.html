Spaces, modalities, and variables

The agent operates in a continuous physical environment and is endowed with \(N_s\) sensory modalities plus a policy space. Raw input for modality \(i\) is a vector \(s^{(i)} \in \mathbb{R}^{D_i}\). The policy is described by a parameter vector \(\pi \in \mathbb{R}^{D_\pi}\) — concretely, the weight matrix of the online controller neural network.

Definition 1 — Modality set

The complete set of input modalities is \(\mathcal{M} = \{s^{(1)},\ldots,s^{(N_s)},\pi\}\). In the canonical instantiation: \(s^{(1)} = v\) (foveal vision, \(\mathbb{R}^{10\times10\times3}\)), \(s^{(2)} = ss\) (somatosensory / touch, \(\mathbb{R}^{40}\)), \(s^{(3)} = p\) (proprioception, \(\mathbb{R}^5\)), \(\pi \in \mathbb{R}^{75\times5}\). The effect modalities are \(\mathcal{M}_{\mathrm{eff}} = \{ss, p\}\); vision is the condition modality; \(\pi\) is the action modality.

A shared internal representation space \(\mathcal{Z} \subset \mathbb{R}^2\) is defined a priori as a 2-dimensional integer lattice of \(K = K_1 \times K_2\) nodes. Each node \(j \in \{1,\ldots,K\}\) carries a fixed grid position \(\mathbf{p}_j \in \mathbb{R}^2\), assigned once before training and never modified. The set of all grid positions is \(\mathbb{G} = \{\mathbf{p}_1,\ldots,\mathbf{p}_K\}\). Distances between nodes are Euclidean distances in grid space: \(\|j-k\|_{\mathbb{G}} := \|\mathbf{p}_j - \mathbf{p}_k\|\).

Each modality \(m\in\mathcal{M}\) is equipped with its own prototype matrix \(W^{(m)} \in \mathbb{R}^{K\times D_m}\), where \(\mathbf{w}^{(m)}_j \in \mathbb{R}^{D_m}\) is the prototype of node \(j\). These are the only learnable parameters. For each input \(\mathbf{x}\) the Best Matching Unit (BMU) is:

\[r(\mathbf{x};\, W^{(m)}) = \arg\min_{k\in\{1,\ldots,K\}} \|\mathbf{x} - \mathbf{w}^{(m)}_k\|\]
(1)
Key notational convention

When we write \(E(W)\) the assignment \(r(W)\) is always implicitly re-derived from the current weights — it is a deterministic, piecewise-constant function of \(W\), and the source of non-convexity. When we write \(E(W \mid r)\) the assignment vector \(r\) is held fixed as a vector of constants. These two objects have fundamentally different analytical properties.

The WTA operator family: k-means, SOM, STM

All three algorithms minimise the same general energy functional:

\[\mathcal{L}(W) = \frac{1}{2}\sum_{i=1}^N \sum_{j=1}^K \phi_{i,j}\,\|\mathbf{x}_i - \mathbf{w}_j\|^2\]
(2)

They differ only in the winner-takes-all (WTA) operator \(\phi_{i,j}\), which controls how much node \(j\) participates in the update for input \(\mathbf{x}_i\):

AlgorithmWTA operator \(\phi_{i,j}\)Character
\(k\)-means \(\mathbf{1}[j = r_i]\) hard, no topology
SOM \(\exp\!\left(-\dfrac{\|j-r_i\|^2}{2\sigma_r^2}\right)\) soft, topology, unsupervised
STM \(\exp\!\left(-\dfrac{\|j-r_i\|^2}{2\sigma_r^2}\right)\cdot\exp\!\left(-\dfrac{\|j-t_i\|^2}{2\sigma_t^2}\right)\) soft, topology, supervised
Definition 2 — STM WTA operator

\[ \phi^{\mathrm{STM}}_{i,j} = \underbrace{\exp\!\left(-\frac{\|j-r_i\|^2}{2\sigma_r^2}\right)}_{\text{neighbourhood term}} \cdot \underbrace{\exp\!\left(-\frac{\|j-t_i\|^2}{2\sigma_t^2}\right)}_{\text{anchor term}} \] Here \(t_i \in \{1,\ldots,K\}\) is the anchor index for input \(\mathbf{x}_i\): the desired node in \(\mathcal{Z}\) where \(\mathbf{x}_i\) should be represented after training. The anchor vector \(\mathbf{t} = (t_1,\ldots,t_N)\) is fixed throughout training. \(\sigma_r > 0\) is annealed; \(\sigma_t > 0\) is held fixed. The two factors play distinct roles: the neighbourhood term diffuses the update from the winner \(r_i\) to neighbouring nodes (producing topological continuity); the anchor term suppresses the update for node \(j\) if \(j\) is far from the desired position \(t_i\) — regardless of how close \(\mathbf{w}_j\) is to \(\mathbf{x}_i\) in input space. Node \(j\) receives a significant update only when both conditions hold simultaneously. Since both factors are Gaussian, \(\phi^{\mathrm{STM}}_{i,j} > 0\) for all \((i,j)\): every node receives a non-zero update at every step.

Limiting cases

As \(\sigma_t\to\infty\) the anchor term flattens and STM reduces to SOM. As \(\sigma_r\to 0\) the neighbourhood collapses and STM reduces to a label-modulated \(k\)-means with assignment rule \(r_i^* = \arg\min_k \exp(-\|k-t_i\|^2/2\sigma_t^2)\|\mathbf{x}_i-\mathbf{w}_k\|^2\). In the alignment architecture the anchor \(t_i\) is not set by an experimenter but computed on-the-fly as the grid representation of the currently selected policy (§7).

The STM energy function: definition and analytical properties

Definition 3 — STM energy function

Given dataset \(X\), anchor vector \(\mathbf{t}\), prototype matrix \(W\), and assignment \(r = r(W)\):

\[E(W) = \frac{1}{2}\sum_{i=1}^N\sum_{j=1}^K \exp\!\left(-\frac{\|j-r_i(W)\|^2}{2\sigma_r^2}\right) \exp\!\left(-\frac{\|j-t_i\|^2}{2\sigma_t^2}\right) \|\mathbf{x}_i - \mathbf{w}_j\|^2\]
(3)

Variables: \(W \in \mathbb{R}^{K\times M}\) learnable; \(r(W)\in\{1,\ldots,K\}^N\) derived, piecewise-constant in \(W\); \(\mathbf{t}\in\{1,\ldots,K\}^N\) fixed. Parameters: \(\sigma_r > 0\) annealed; \(\sigma_t > 0\) fixed. Analytical properties: non-convex and non-smooth in \(W\) due to \(r(W)\); strictly convex in \(W\) for fixed \(r\); bounded below by zero.

Two sources of non-convexity

From the neighbourhood term. The BMU \(r_i(W)\) is piecewise-constant: as \(W\) changes, inputs cross Voronoi cell boundaries and switch BMU. At each boundary the first Gaussian factor in \(\phi_{i,j}\) changes discontinuously, creating a jump in \(E\). The gradient \(\nabla_W E\) is undefined at these boundaries.

From the reconstruction term. Even with \(r\) fixed, the composition of a piecewise-constant weight matrix with a quadratic form yields a globally non-convex, non-smooth function.

Decomposition by node

Because \(\|\mathbf{x}_i - \mathbf{w}_j\|^2\) depends only on \(\mathbf{w}_j\), the energy decomposes node-wise for fixed \(r\):

\[E(W \mid r) = \sum_{j=1}^K E_j(\mathbf{w}_j;\, r), \qquad E_j(\mathbf{w}_j;\,r) = \frac{1}{2}\sum_{i=1}^N \phi_{i,j}(r_i)\,\|\mathbf{x}_i - \mathbf{w}_j\|^2\]
(4)

With \(r\) fixed the nodes are decoupled: each \(E_j\) is a strictly convex quadratic in \(\mathbf{w}_j\) alone, since \(\sum_i \phi_{i,j} > 0\) always (Gaussians are strictly positive). This decomposition is the key to the M-step closed form.

Batch algorithm as block coordinate descent

The batch STM algorithm alternates between minimisation over two disjoint variable blocks: the assignment vector \(r\) and the prototype matrix \(W\).

E-step: minimisation over \(r\)

With \(W\) held fixed, each \(r_i\) is minimised independently:

\[r_i^{(t+1)} = \arg\min_{k\in\{1,\ldots,K\}} \underbrace{\sum_{j=1}^K \exp\!\left(-\frac{\|j-k\|^2}{2\sigma_r^2}\right)\exp\!\left(-\frac{\|j-t_i\|^2}{2\sigma_t^2}\right)\|\mathbf{x}_i - \mathbf{w}_j^{(t)}\|^2}_{=:\;\Psi_i(k)}\]
(5)

\(\Psi_i(k)\) is the total \(\phi\)-weighted reconstruction error resulting from assigning \(r_i = k\). The exact E-step costs \(O(NK^2)\). In the limit \(\sigma_r\to 0\): \(\Psi_i(k)\to\exp(-\|k-t_i\|^2/2\sigma_t^2)\|\mathbf{x}_i-\mathbf{w}_k\|^2\) — a modulated nearest-prototype rule where node \(k\) wins only if it is simultaneously close to \(\mathbf{x}_i\) in input space and close to anchor \(t_i\) in grid space.

Approximate E-step (standard implementation)

The common implementation uses \(r_i^{\mathrm{approx}} = \arg\min_k \|\mathbf{x}_i - \mathbf{w}_k\|\), which is the exact E-step with \(\sigma_t\to\infty\). Cost \(O(NKM)\). The anchor still shapes prototypes through the M-step but does not influence which node wins competition.

M-step: minimisation over \(W\)

With \(r^{(t+1)}\) fixed, the node decomposition (4) yields \(K\) independent strictly convex sub-problems. Setting \(\partial E_j / \partial \mathbf{w}_j = 0\):

Definition 4 — M-step closed-form solution
\[\mathbf{w}_j^{(t+1)} = \frac{\displaystyle\sum_{i=1}^N \phi_{i,j}(r_i^{(t+1)})\,\mathbf{x}_i}{\displaystyle\sum_{i=1}^N \phi_{i,j}(r_i^{(t+1)})}\]
(6)

Each prototype is updated to the \(\phi\)-weighted centroid of all training inputs. The weight \(\phi_{i,j}\) is large only for inputs whose BMU is near \(j\) and whose anchor \(t_i\) is near \(j\) — both in grid space. The denominator \(\sum_i \phi_{i,j} > 0\) always, so the update is well-defined for every node including those that are nearest prototype for no input.

The corresponding online (stochastic gradient) form is:

\[\mathbf{w}_j \;\leftarrow\; \mathbf{w}_j + \eta^u_j\,\phi_{i,j}\,(\mathbf{x}_i - \mathbf{w}_j)\]
(7)

where \(\eta^u_j\) is a local, prototype-specific learning rate (see §9).

Convergence theory

Proposition 1 — M-step does not increase energy

For fixed \(r^{(t+1)}\) and fixed \(\sigma_r, \sigma_t > 0\): \[E\!\left(W^{(t+1)} \mid r^{(t+1)}\right) \;\leq\; E\!\left(W^{(t)} \mid r^{(t+1)}\right)\] with equality iff \(W^{(t+1)} = W^{(t)}\).

Proof. With \(r\) fixed, \(E(\cdot\mid r)\) decomposes into \(K\) independent strictly convex quadratics \(E_j(\mathbf{w}_j)\). The M-step sets each \(\mathbf{w}_j^{(t+1)}\) to the unique global minimiser of \(E_j\). Hence \(E_j(\mathbf{w}_j^{(t+1)}) \leq E_j(\mathbf{w}_j^{(t)})\) for each \(j\). Summing over \(j\) gives the result. \(\square\)

Theorem 1 — Block-CD monotone non-increase (fixed \(\sigma\))

With \(\sigma_r\) and \(\sigma_t\) held constant across epochs, the sequence \(\{E^{(t)}\}_{t\geq0}\) defined by \(E^{(t)} = E(W^{(t)}, r^{(t)})\) satisfies: \[E^{(t+1)} \;\leq\; E^{(t)} \quad \forall\, t \geq 0\]

Proof. The E-step replaces \(r^{(t)}\) with \(r^{(t+1)} = \arg\min_r E(W^{(t)}, r)\): \[E(W^{(t)}, r^{(t+1)}) \;\leq\; E(W^{(t)}, r^{(t)})\] The M-step gives (by Proposition 1): \[E(W^{(t+1)}, r^{(t+1)}) \;\leq\; E(W^{(t)}, r^{(t+1)})\] Chaining: \(E^{(t+1)} \leq E^{(t)}\). \(\square\)

Corollary 1 — Convergence of the energy sequence

The sequence \(\{E^{(t)}\}\) is monotone non-increasing and bounded below by zero. By the monotone convergence theorem, \(E^{(t)} \to E^*\) for some \(E^* \geq 0\).

Scope and limitations

Corollary 1 guarantees convergence of the energy value, not of the iterates \((W^{(t)}, r^{(t)})\). It does not guarantee \(W^{(t)}\to W^*\) for a fixed point (iterates may oscillate at the same energy level), nor \(E^* = E_{\min}\) (convergence to local minima or saddle points is possible). Crucially, Theorem 1 does not hold across epochs during \(\sigma_r\)-annealing: when \(\sigma_r\) decreases between epochs the functional \(E\) itself changes shape, so the energy can rise slightly at epoch boundaries. The M-step guarantee holds strictly only within each epoch at fixed \(\sigma_r\). The practical convergence of \(C_{\mathrm{tot}}\to 1\) (§9) is therefore an empirical property of the full algorithm, not a corollary of Theorem 1.

Point and grid representations; inverse mapping

Definition 5 — Point and grid representations

Given stimulus \(\mathbf{x}\in\mathbb{R}^{D_m}\) with BMU \(r = r(\mathbf{x}; W^{(m)})\) in modality \(m\):

The point representation \(\mathbf{x}_m \in \mathcal{Z}\) is the 2D coordinate of the BMU: \(\mathbf{x}_m = \mathbf{p}_{r}\).

The grid representation \(\mathbf{r}_m \in \mathbb{R}^K_{\geq 0}\) is a radial-basis activation over all nodes: \[r_m(j) = \exp\!\left(-\frac{\|j - \mathbf{x}_m\|^2}{2\sigma_{\mathrm{rbf}}^2}\right), \quad j = 1,\ldots,K\]

The grid representation enables inverse mapping: given any target coordinate \(\hat{\mathbf{z}}\in\mathcal{Z}\), reconstruct a pattern in modality \(m\) as:

\[\hat{\mathbf{d}}^{(m)}(\hat{\mathbf{z}}) = \bigl(W^{(m)}\bigr)^{\!\top} \mathbf{r}(\hat{\mathbf{z}})\]
(8)

where \(\mathbf{r}(\hat{\mathbf{z}})\in\mathbb{R}^K\) is the radial-basis activation centred on \(\hat{\mathbf{z}}\). This is used by the offline controller to reconstruct policies from internal goal representations.

The shared anchor and cross-modal alignment

The key innovation of the alignment architecture is that all STMs \(\{W^{(m)}\}_{m\in\mathcal{M}}\) are updated simultaneously with the same anchor — the grid representation of the currently selected policy — as their common \(t_i\). This transforms independent per-modality learning into a jointly constrained problem: different modalities are forced into topological correspondence.

Definition 6 — Shared anchor and joint STM update

At the start of each episode, policy \(\hat{\pi}\) is selected and its point representation \(\hat{\mathbf{x}}_\pi = \mathbf{x}_\pi(\hat{\pi})\) is computed. For all stimuli collected in that episode, the shared anchor label is \(t_i = \hat{\mathbf{x}}_\pi\). The WTA operator for modality \(m\) is therefore: \[ \phi^{(m)}_{i,j} = \exp\!\left(-\frac{\|j - r^{(m)}_i\|^2}{2(\sigma^u_j)^2}\right)\exp\!\left(-\frac{\|j - \hat{\mathbf{x}}_\pi\|^2}{2(\sigma^u_j)^2}\right) \] All \(|\mathcal{M}|\) STMs are updated with this same anchor. As a result, corresponding positions in \(\mathcal{Z}\) come to encode compatible information across all modalities: a point \(\mathbf{z}\in\mathcal{Z}\) represents simultaneously a visual condition, a policy, and its sensorimotor effects.

The online prototype update for modality \(m\) is:

\[\mathbf{w}^{(m)}_j \;\leftarrow\; \mathbf{w}^{(m)}_j + \eta^u_j\,\phi^{(m)}_{i,j}\,\bigl(\mathbf{d}^{(m)} - \mathbf{w}^{(m)}_j\bigr)\]
(9)

where \(\mathbf{d}^{(m)}\) is the sensory state collected at successful timesteps (§8) and \(\eta^u_j\) is the local learning rate (§9).

The intrinsic alignment signal

Definition 7 — Internal match

At timestep \(t\), let \(\mathbf{x}^{(m)}_t\) denote the point representation of modality \(m\) and \(\hat{\mathbf{x}}_\pi\) the goal prototype coordinate. The per-modality internal match is: \[\mu^{(m)}_t = \exp\!\left(-\frac{\|\mathbf{x}^{(m)}_t - \hat{\mathbf{x}}_\pi\|^2}{2\sigma_\mu^2}\right) \in (0,1]\] The overall internal match averages over effect modalities only (vision excluded, as visual change during manipulation is not primarily caused by the current policy): \[\psi_t = \frac{1}{|\mathcal{M}_{\mathrm{eff}}|}\sum_{m\in\mathcal{M}_{\mathrm{eff}}} \mu^{(m)}_t\]

Equivalently (2023 formulation), the mean distance across all modalities is first computed and then converted:

\[\hat{\psi}_t = \frac{\displaystyle\sum_{i=1}^{N_s}\|\mathbf{x}^{(i)}_t - \hat{\mathbf{x}}_\pi\| + \|\mathbf{x}^\pi_t - \hat{\mathbf{x}}_\pi\|}{N_s + 1}, \qquad \psi_t = \exp\!\left(-\frac{\hat{\psi}_t^2}{2\sigma_\psi}\right)\]
(10)

The intrinsic signal retains only positive increments:

\[c_t = \begin{cases}\psi_t & \text{if } \psi_t - \psi_{t-1} > \theta_\delta \\ 0 & \text{otherwise}\end{cases}\]
(11)

Success criterion and timestep selection

Timestep \(t\) is successful — and its sensorimotor states retained for the STM update — iff:

\[\mu^{(ss)}_t > \mu^{(ss)}_{t-1} \quad\text{(local somatosensory increase)}\qquad\text{and}\qquad\psi_t > \max_{\tau

The set \(\mathcal{T}\subseteq\{1,\ldots,T_{\mathrm{ep}}\}\) of selected timesteps provides the dataset \(\{\mathbf{d}^{(m)}_t\}_{t\in\mathcal{T}}\) for the batch M-step.

Intrinsic motivation interpretation

The signal \(c_t\) is derived entirely within \(\mathcal{Z}\), without any external reward. An agent maximising \(\sum_t c_t\) is intrinsically motivated to produce sensory representations that converge towards its policy representation — i.e., to increase its own competence: the ability to reliably cause predictable sensory effects through action.

Competence prediction and hyperparameter modulation

A predictor component estimates the expected match \(\hat{c}(\hat{\mathbf{x}}_\pi)\) for each goal prototype. After each epoch the stored value is updated:

\[c_{\hat{\mathbf{x}}_\pi} \;\leftarrow\; c_{\hat{\mathbf{x}}_\pi} + \alpha\,\psi_{\hat{\mathbf{x}}_\pi}\]
(12)

Predictions are computed via kernel-weighted average over the grid:

\[\hat{c}(\hat{\mathbf{x}}_\pi) = \frac{\sum_j \mathbf{r}_{\hat{\mathbf{x}}_\pi}(j)\,c_j}{\sum_j \mathbf{r}_{\hat{\mathbf{x}}_\pi}(j)}, \qquad C_{\mathrm{tot}} = \frac{1}{K}\sum_{j=1}^K \hat{c}(\mathbf{j})\]
(13)

Three hyperparameters are then modulated locally by both global and local competence:

\[\eta^u_j = \eta_{\min} + (\eta_{\max}-\eta_{\min})\underbrace{(1-\tanh 3C_{\mathrm{tot}})}_{\text{global gate}}\underbrace{(1-\tanh\hat{c}(\mathbf{j}))}_{\text{local gate}}\]
(14)
\[\sigma^u_j = \sigma^u_{\min} + (\sigma^u_{\max}-\sigma^u_{\min})(1-\tanh 3C_{\mathrm{tot}})(1-\tanh\hat{c}(\mathbf{j}))\]
(15)
\[\sigma^n_j = \sigma^n_{\min} + (\sigma^n_{\max}-\sigma^n_{\min})(1-\tanh 3C_{\mathrm{tot}})(1-\tanh\hat{c}(\mathbf{j}))\]
(16)

Policy exploration noise is \(\boldsymbol{\epsilon}\sim\mathcal{N}(\mathbf{0},\sigma^n_{\hat{\mathbf{x}}_\pi}\mathbf{I})\), giving executed policy \(\pi = \hat{\pi}+\boldsymbol{\epsilon}\). Equations (14–16) implement competence-based adaptive annealing: high-competence regions (high \(\hat{c}\)) receive small updates and little noise; low-competence regions receive large updates and extensive exploration. This asymmetric modulation is the mechanism enabling lifelong learning without catastrophic forgetting.

Relation to the convergence theorem

Equations (14–16) constitute adaptive \(\sigma_r\)-annealing. By Theorem 1, the M-step guarantee \(E^{(t+1)}\leq E^{(t)}\) holds strictly only when \(\sigma_r\) is fixed within an epoch. Across epoch boundaries the changing \(\sigma^u_j\) alters the energy landscape; local energy increases at epoch transitions are therefore possible and expected. The practical convergence \(C_{\mathrm{tot}}\to 1\) is an empirical property of the full algorithm.

Convergence of alignment and semantic grounding

Proposition 2 — Alignment equilibrium

The algorithm reaches equilibrium when \(C_{\mathrm{tot}}\to 1\). At equilibrium, for any \(\mathbf{z}\in\mathcal{Z}\) and modality \(m\), the inverse mapping \(\hat{\mathbf{d}}^{(m)}(\mathbf{z})\) reconstructs a sensory state causally consistent with policy \(\hat{\pi}(\mathbf{z})\): executing \(\hat{\pi}(\mathbf{z})\) in the environment reliably produces sensory states whose point representations converge to \(\mathbf{z}\).

Definition 8 — Grounding by convergence (success semantics)

A point \(\mathbf{z}\in\mathcal{Z}\) refers to environmental condition \(C\) iff: \[C \text{ obtains} \;\Longleftrightarrow\; \psi_t\to 1 \text{ when the agent executes }\hat{\pi}(\mathbf{z})\] The semantic content of \(\mathbf{z}\) is thus fixed entirely by the causal structure of agent–environment interaction as reflected in \(\psi_t\), with no appeal to further semantic notions.

The triadic goal structure and affordance space

Once all STMs are aligned, every point \(\mathbf{z}\in\mathcal{Z}\) simultaneously encodes three components recoverable via inverse mapping (8):

\[g(\mathbf{z}) = \Bigl(\underbrace{\hat{\mathbf{d}}^{(v)}(\mathbf{z})}_{\text{condition (vision)}},\quad \underbrace{\hat{\pi}(\mathbf{z})}_{\text{action (policy)}},\quad \underbrace{\hat{\mathbf{d}}^{(ss)}(\mathbf{z}),\;\hat{\mathbf{d}}^{(p)}(\mathbf{z})}_{\text{effect (touch + proprio)}}\Bigr)\]

The full goal space is the image of \(\mathcal{Z}\) under this triadic mapping: \(\mathcal{G} = \{g(\mathbf{z}):\mathbf{z}\in\mathcal{Z}\}\).

Proposition 3 — Topological alignment as affordance map

After convergence, \(\mathcal{G}\) constitutes a low-dimensional manifold of possible interactions. Each point \(g(\mathbf{z})\in\mathcal{G}\) encodes an affordance: a stable relational structure between a perceptual condition, an executable action, and a predictable sensorimotor effect. Neighbouring points in \(\mathcal{Z}\) encode structurally similar affordances, by the topology-preserving property of STMs.

Necessity of action coupling — formal content of the yoked-control result

A passive (parasite) agent receiving the same sensory stream \(\{s^{(m)}_t\}\) as an active agent can achieve \(C_{\mathrm{tot}}\to 1\): the energy \(E(W)\) decreases regardless of whether the anchor \(\hat{\mathbf{x}}_\pi\) is causally linked to sensory effects. However, since the parasite's policy is decoupled from those effects, the success condition \(\psi_t\to 1\) does not imply that executing \(\hat{\pi}_{\mathrm{par}}(\mathbf{z})\) reproduces the corresponding effect in the environment. Alignment without active policy coupling is therefore sufficient for energy minimisation but insufficient for the emergence of \(\mathcal{G}\) as a genuine affordance map. This is the formal content of Result 2 (Zubek et al., 2024).
